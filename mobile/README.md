# 같이 달려 — 휴대폰 웹앱 (PWA, 시연판)

Pleos 차량이 아닌 차로 함께 가는 사람, 동승자가 **설치 없이 초대 링크로** 참여하는 휴대폰 화면입니다.
피그마 ‘06 디자인 — 모바일 앱’ M-01 ~ M-15 를 그대로 옮겼고, 차량 앱과 같은 흰 바탕 × 디지털 블루(#2563EB) · Asta Sans 를 씁니다.

> **시연판**: 동기화 서버 없이 시나리오 A(6대 · 잠실 → 강릉 안목해변)를 따라갑니다.
> 위치와 메시지는 이 기기 밖으로 나가지 않고, 다른 차의 움직임·응답은 시연 데이터입니다.
> 화면 왼쪽 ‘시연’ 탭에서 원하는 장면(07:25 대기실 ~ 10:49 도착)으로 바로 넘길 수 있습니다.

## 실행

```bash
cd mobile
npm install
npm run dev        # http://localhost:5173  (휴대폰에서 보려면 npm run dev -- --host)
npm test           # 모임 규칙 단위 테스트 (vitest)
npm run build      # dist/ — 정적 호스팅 어디든 (상대 경로 · 해시 주소)
```

위치 · 음성 인식 · 화면 켜 두기는 **https** 또는 localhost 에서만 열립니다.

## 쓰는 브라우저 기능

| 기능 | API | 없을 때 |
|---|---|---|
| 소리 내어 읽기 | Web Speech `speechSynthesis` (ko-KR) · 한 번에 하나, 안전 안내 먼저 | 자막만 |
| 말로 투표 · 말로 하기 | `SpeechRecognition` (Chrome 은 Google 서버 인식) | 버튼으로 답하기 · 동승자가 대신 |
| 위치 | Geolocation `watchPosition` — 출발 안내부터 여행이 끝날 때까지만, 정확도·측정 시각 표시 | ‘보기만’ 참여 |
| 화면 켜 두기 | Screen Wake Lock (운전자 모드로 움직이는 동안) | 거치대 안내 |
| 진동 · 공유 · 복사 | `navigator.vibrate` · Web Share · Clipboard | 복사로 대신 |
| 다른 내비로 열기 | 카카오맵 웹 링크 · 네이버 지도 `nmap://`(없으면 웹) · 티맵 `tmap://` | 웹 지도 |
| 홈 화면에 추가 | Web App Manifest · 서비스 워커(한 번 연 화면은 연결이 끊겨도 열림) | — |

## 차량 앱과 같은 규칙

`src/domain/` 은 차량 앱(Kotlin) 도메인을 그대로 옮긴 것입니다. 실서비스에서는 한쪽 규칙을 서버 · 공용 모듈로 모읍니다.

- 내 메시지 검사(2~20자 · 재촉/위험 운전 · 연락처 · 겹침, 말로 보낸 문장은 40자) — `QuickMessagePolicy`
- 보내기 제한(2초 두 번 눌림 · 같은 메시지 30초 · 1분 4번) — `SendGuard`
- 쉬어가기 투표(제안자 포함 과반 · 1분 마감 · 과반 불가능하면 바로 종료) — `RestVoteEngine`
- 안내 문장과 한국어 조사 — `Announcements`, `Josa`
